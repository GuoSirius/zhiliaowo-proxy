# 知了窝 H5 数据契约（Data Contract）

> 用途：本文件定义 H5 生成器所依赖的全部**数据来源、字段 Schema 以及与 docs/ 图示 H5 的映射关系**。
> 它是「区块库 API 规范」的上游输入——区块组件的 props 字段、管理后台录入表单、服务端代理开放平台 API 均以此为准。
> 调研来源：`docs/知了窝开放平台对接文档.pdf`（43 页，开放组件 5 个 + 开放 API 7 个）。
> 注：以下 TypeScript 类型为**契约描述（非实现代码）**。

---

## 1. 平台开放 API 总览

| 项 | 值 |
|---|---|
| Base URL | `https://open.zhiliaowo.cn/openapi/v12` |
| 组件 URL | `https://open.zhiliaowo.cn/v_widget/v11` |
| 通用必填参数 | `brand`（授权标准品牌名）、`appId`（品牌唯一标识）、`timestamp`（毫秒时间戳） |
| 可选参数 | `lang=zh_CN\|en_US`（中英切换，默认中文） |
| 通用返回信封 | `{ "msg": string, "code": 200, "result": ... }` |

> 说明：开放 API 只返回数据、不含渲染；H5 生成器即消费这些 API 并自行渲染。

---

## 2. H5 用到的接口清单

| # | 用途 | 路径 | result 类型 | 对应 H5 区块 |
|---|---|---|---|---|
| 2.1 | 品牌文献统计概况 | `GET /brand/statistics` | `StatSummary` | 核心数据卡 |
| 2.2 | 品牌×SPU 引用概况 | `GET /brand/goods/cite_stat?sku=` | `StatSummary` | 商品级数据卡 |
| 2.3 | 历年累计数量分布 | `GET /brand/chart/paper_sum` | `SeriesPoint[]` | 累计柱状图 |
| 2.4 | 年度数量分布 | `GET /brand/chart/paper_year` | `SeriesPoint[]` | 年度柱状图 |
| 2.5 | 产品引用数量列表 | `GET /brand/goods/cite_num` | `CiteCount[]` | 产品引用排行 |
| 2.6 | 品牌文献列表（可筛选） | `GET /list/brand/paper` | `Page<PaperItem>` | 文献列表 / 文献解析 |
| 2.7 | 产品文献列表 | `GET /list/product/paper` | `Page<PaperItem>` | 产品文献 |

## 3. 数据模型（契约类型）

```ts
/** 文献统计概况：2.1 / 2.2 共用 */
interface StatSummary {
  totalCount: number;   // 总文献数量
  totalFactor: number;  // 总影响因子
  maxFactor: number;    // 最高影响因子
  avgFactor: number;    // 平均影响因子
}

/** 时序点：2.3 历年累计 / 2.4 年度数量 */
interface SeriesPoint {
  name: string;   // 年份，如 "2024"
  value: number;  // 文献数量
}

/** 产品引用数量：2.5 */
interface CiteCount {
  name: string;   // 货号（sku），如 "ET1703-40"
  value: number;  // 引用数量
}

/** 文献条目：2.6 / 2.7，分页返回 */
interface PaperItem {
  id: string;
  title: string;
  doi?: string;
  summary?: string | null;     // 摘要，多数情况下为 null
  pmid?: string | null;
  journal: string;             // 期刊名，如 "NATURE MEDICINE"
  volume?: string;             // 卷
  issue?: string;              // 期
  page?: string;               // 页码
  feature?: string;            // 期刊封面图 URL（OSS）
  pubTime: string;             // 发表日期 "YYYY-MM-DD"
  factor: number;              // 影响因子
  authors: string;             // 全部作者（逗号分隔）
  authorName?: string;         // 一作
  country?: string;            // 一作国家
  province?: string;
  city?: string;
  org?: string;                // 一作单位
  CorAuthorName?: string;      // 通讯作者
  CorCountry?: string;
  CorProvince?: string;
  CorCity?: string;
  CorOrg?: string;
  jcr?: string;                // 中科院分区
  level?: string;              // 分区等级 L1~L4（一区~四区）
  url?: string;                // 原文链接
  cnFields?: string[];         // 中图分类字段，如 ["肿瘤学","免疫学"]
  products?: PaperProduct[];   // 关联引用产品
}

/** 文献关联的引用产品：嵌套于 PaperItem.products */
interface PaperProduct {
  goodsLabel: string;          // 商品名（无货号时仅展示名称）
  goodsSpu?: string;           // 货号
  goodsCas?: string;           // CAS 号
  goodsUrl?: string;          // 商品链接
  target?: string;             // 靶点
  application?: string | null; // 应用方法（WB/IHC…）
  specie?: string;             // 物种
  cnSpecie?: string | null;
  dilution?: string | null;    // 稀释比
  sample?: string;             // 样本
  cnSample?: string | null;
  paperProductPictureList?: PaperPicture[];  // 实验图片
}

/** 文献中的实验图：嵌套于 PaperProduct.paperProductPictureList */
interface PaperPicture {
  id: string;
  picUrl: string;              // 实验图片地址
  description: string;         // 图片描述
  rawUrl: string;              // 原文对应链接
}

/** 分页包装：2.6 / 2.7 的 result */
interface Page<T> {
  totalCount: number;
  totalPage: number;
  pageNo: number;
  pageSize: number;
  data: T[];
}
```

## 4. 与 docs/ 图示 H5 的字段映射

| docs 图示 | 区块 | 取数字段 |
|---|---|---|
| 核心数据卡（总文献/总IF/最高IF/平均IF） | StatCardGroup | `StatSummary.totalCount / totalFactor / maxFactor / avgFactor` |
| 近 10 年 SCI 年度数量柱状图 | BarChart | `SeriesPoint[]`（来自 2.4） |
| 历年累计数量柱状图 | BarChart | `SeriesPoint[]`（来自 2.3） |
| 季度 / 分类数据 | QuarterGrid | 由 `list/brand/paper` 聚合 `cnFields` 或手动 |
| 小结列表 | SummaryList | 运营文案（非 API） |
| 文献列表（多篇） | PaperListBlock | `Page<PaperItem>.data` |
| 文献解析（单篇深度） | ArticleBlock | 单条 `PaperItem`：`feature`(封面) / `title` / `factor` / `authors` / `cnFields`(关键词) / `products`(产品推荐) / `paperProductPictureList`(机制/实验图) |
| 品牌头 / 页脚 | BrandHeader / BrandFooter | 来自 BrandTheme 配置（见区块库 API 规范），非开放 API |

## 5. 数据获取策略（分阶段）

| 阶段 | 来源 | 说明 |
|---|---|---|
| P0 手动 | 用户填 JSON | 表单字段严格对齐本契约第 3 节，零 API 依赖即可跑通 |
| P1 代理 | zhiliaowo-proxy `/api/h5/proxy/*` | 服务端代理开放 API，套用现有内存/Redis 缓存抽象 |
| P2 自动 | 定时拉取 | 每月自动拉 `/brand/statistics` + `/list/brand/paper` 预填月度/半年 H5 草稿 |

---

## 6. 注意事项 / 已知约束

1. **鉴权三参数** `brand/appId/timestamp` 缺一不可；`timestamp` 为毫秒级，需服务端注入以免客户端时间漂移。
2. **`summary` 常为 null**：文献解析 H5 的「摘要」段落应允许运营手动补充，不能强依赖 API。
3. **产品图缺省**：`paperProductPictureList` 可能为空，区块需有占位图。
4. **品牌名校验**：`brand` 必须是「知了窝官方校验通过的品牌名称」，H5 多品牌主题中的 `brandKey` 必须与之一致。
5. **图片域名**：期刊封面/实验图来自 `zlwshop-oss.oss-cn-beijing.aliyuncs.com`，导出长图时需注意跨域（建议服务端代理或 `<img crossorigin>`）。
